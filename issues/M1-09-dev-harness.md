# [M1-09] 내부 개발 하니스 (빌드 플래그 세션 진입)

> 정본 트래커는 GitHub Issues(`gh`) — 본 파일은 승격 전 계획 백로그(`/to-issues`).
> **마일스톤 순서 규약(B3):** M1 세션 진입은 **빌드 플래그 뒤 내부 하니스**(비사용자 노출). **M3-08(사용자 대면 홈)이 이를 대체·폐기**한다.

## 컨텍스트
M1 핵심 루프를 온보딩/한도/인증 없이 개발·테스트하기 위한 하드코딩 진입점. 사용자에게 노출되지 않는다.

## SoT (재결정 금지 — 인용만)
- 스펙: [PRD.md](../PRD.md) §14(M1), 부록 B B3(L363)
- 시각: 해당 없음(개발 전용)

## 목표
빌드 플래그가 켜진 디버그 빌드에서 하드코딩된 레벨·주제·길이로 곧장 세션에 진입해 핵심 루프를 돌린다.

## 범위
- In: 빌드 플래그 게이팅, 하드코딩 세션 파라미터 진입 화면, 한도 게이트 우회(개발용).
- Out: 실제 온보딩/홈/한도(M3), 프로덕션 노출.

## 의존성
- Blocked by: M0-09
- Blocks: M3-08 (대체 관계)

## 수용 기준
- [ ] 빌드 플래그 OFF 시 진입점 완전 비노출(프로덕션 안전)
- [ ] 플래그 ON 시 하드코딩 파라미터로 세션 진입
- [ ] M3-08 완료 시 제거 가능하도록 격리(대체 엣지 문서화)

## 검증
릴리즈 빌드에서 진입점 부재 확인. 디버그 빌드 진입 스모크.
