## 1. 목적

홈은 대시보드가 아니라 **학습 시작을 최우선으로 지원하는 허브**다.

사용자는 홈에서 오래 탐색하기보다, 가장 적은 망설임으로 새 대화 세션을 시작해야 한다. 게임화, 학습 상태, 한도 정보, 저장 카드 복기는 모두 이 목적을 방해하지 않는 선에서만 보조한다.

핵심 원칙:
- 첫 사용자는 홈을 거치지 않고 첫 성공 경험으로 직행한다.
- 재방문 사용자는 홈에서 바로 다음 학습을 시작할 수 있어야 한다.
- 홈은 제한/과금/설정보다 학습 행동을 먼저 보여준다.
- 시각 표현은 디자인 시스템에 위임하고, 이 문서는 역할과 상태만 정의한다.

## 2. 사용자 상태

### 2.1 첫 실행 전

동작:
- 앱 실행
- 게스트로 자동 시작
- 온보딩 2문항으로 이동
- 홈은 노출하지 않는다.

이유:
- 첫 60초 안에 성공 경험을 제공하는 것이 PRD의 활성화 핵심이다.

### 2.2 온보딩 후 첫 세션 전

동작:
- 레벨 선택과 관심 상황 선택 후 첫 세션으로 바로 진입한다.
- 첫 세션은 `쉬움`, `5턴`으로 고정한다.
- 레벨 컨트롤, 길이 컨트롤, 직접 입력 주제는 노출하지 않는다.

주제 후보:
- `beginnerFriendly=true` 주제 6개만 사용한다.

### 2.3 첫 세션 완주 직후

홈보다 먼저 처리할 것:
- 세션 요약
- 작은 성취감
- 다음 학습 유도
- Google 저장 제안

Google 제안:
- 강제 차단이 아니라 선택형 제안으로 둔다.
- 사용자가 거절해도 앱 사용을 계속할 수 있어야 한다.

### 2.4 재방문

홈이 본격적으로 동작하는 상태다.

홈의 역할:
- 새 대화 세션 시작
- 현재 학습 상태의 가벼운 요약
- 한도 도달 등 필요한 상태 안내

### 2.5 미완 / 이탈 세션 복귀

정책:
- 로컬 recoverable snapshot이 있으면 이어하기를 제공한다.
- 로컬 snapshot이 없으면 새로 시작한다.
- 서버 턴 저장소 기반 복구는 v1 범위가 아니다.
- 생성 성공 후 학습을 완료하지 않았더라도 한도는 이미 소모될 수 있다.
- XP/streak는 요약 라우트 진입 전까지 적립하지 않는다.

snapshot 계약(확정):
- **저장 범위:** `dialogue-learning-flow.md` §10 "필수 상태 보존" 목록 그대로 — `sessionId`, `idempotencyKey`, `remaining`, 대본, 현재 턴, 대화 기록, 진행 상태, 요청 토큰/stale guard, slim 피드백 상태.
- **만료:** 시간 만료 없음. 미완 세션 스냅샷은 새 세션이 실제로 시작될 때 폐기한다. 대화가 `Completed`에 도달하면 더 이상 이어가기 대상이 아니므로 즉시 폐기한다.

복귀 프롬프트:
- 문구: `이어서 할 수 있는 대화가 있어요.`
- 액션: `이어하기`, `새로 시작`

주의:
- "이어하기"는 로컬 복구 가능한 상태가 있을 때만 보여준다.
- 앱 종료, 상태 손실, 장시간 경과 등으로 복구할 수 없으면 이어하기를 보여주지 않는다.

## 3. 재방문 학습 진입 플로우

확정 플로우:

```text
홈 CTA
  -> 주제 선택 화면
  -> 접힌 세션 설정(레벨/길이)
  -> 서버 한도 게이트 및 대본 생성
  -> 대화 학습
```

### 3.1 홈 CTA

메인 CTA:
- `오늘 5분 말하기`

역할:
- 새 대화 세션 시작
- 탭하면 주제 선택 화면으로 이동한다.

원칙:
- 기능 중심 문구보다 행동 중심 문구를 사용한다.
- `대본 생성하기`, `AI 대화 만들기`보다 사용자의 학습 행동을 앞세운다.

### 3.2 주제 선택

지원 범위:
- 추천 주제
- 전체 4그룹
- 직접 입력
- 추천 새로고침

전체 4그룹:
- 일상·입문
- 여행
- 업무·커리어
- 생활·서비스

최근 주제:
- core v1 요구에서 제외한다.
- 현재 확정 Firestore 스키마에 최근 주제 저장소가 없다.
- 필요 시 후속으로 로컬 전용 저장 정책을 별도 결정한다.

### 3.3 직접 입력 주제

정책:
- 큐레이션 우선, 직접 입력은 보조 기능이다.
- 온보딩 첫 세션에서는 직접 입력을 숨긴다.
- 재방문 주제 선택 화면에서는 하단 또는 보조 영역에 둔다.

역할:
- 원하는 상황이 목록에 없을 때 쓰는 escape hatch.

카피 방향:
- `원하는 상황 직접 입력`

### 3.4 추천 새로고침

정책:
- 추천 새로고침은 지원한다.
- `오늘의 추천`으로 고정하지 않는다.
- v1 알고리즘은 **단순 회전(결정적)** 으로 확정한다 — `topics.json`(`android/app/src/main/assets/topics.json`)의 300개 큐레이션 상황을 날짜/인덱스 기반으로 결정적 순환한다. 랜덤·서버 config 기반은 v1 미사용.

주의:
- 단순 회전은 백엔드 작업이 필요 없고 결정적이라 예측 가능하다(랜덤/서버 config는 v1.1 이후 리텐션 데이터로 재검토).
- 새로고침은 선택지를 늘리는 기능이지 홈의 핵심 CTA를 대체하지 않는다.

## 4. 세션 설정

### 4.1 레벨

정책:
- 첫 세션: 노출하지 않음, `쉬움` 고정
- 재방문: `profile.level` 자동 적용
- 변경 위치: 주제 선택 화면의 접힌 세션 설정

옵션:
- 쉬움
- 보통
- 어려움

원칙:
- 사용자가 매번 난이도를 고민하게 만들지 않는다.
- 현재값은 작게 보여주고, 필요할 때만 펼쳐 바꾸게 한다.

### 4.2 길이

정책:
- 첫 세션: 5턴 고정
- 재방문 기본: 5턴
- 선택 옵션: 10턴

이유:
- `오늘 5분 말하기` CTA와 맞춘다.
- 말하기 부담이 있는 사용자가 짧게 완주할 수 있게 한다.
- 더 깊게 학습하려는 사용자는 10턴을 선택할 수 있다.

## 5. 홈 구성

### 5.1 기본 구조

우선순위:
1. 메인 CTA: `오늘 5분 말하기`
2. 작은 게임화 요약
3. 필요할 때만 한도/상태 안내

홈은 기록판이나 설정판이 아니라 다음 학습 시작 화면이다.

### 5.2 게임화 요약

비중:
- 낮은 비중의 상태 요약으로 둔다.
- 메인 CTA보다 낮은 위계로 둔다.

표시 항목:
- 오늘 학습 시간 (홈 중심 지표)
- 연속 학습일 (학습시간과 동급 또는 그 이하)
- XP/포인트 — **백스테이지**: 작게(`· N XP`) 또는 접힘. 정본 위계는 [gamification-emphasis.md](gamification-emphasis.md) §2·§9(완주=streak hero / 홈=학습시간 중심 / XP=백스테이지)를 따른다.

정책:
- 최대 2~3개 지표만 보여준다.
- 강한 보상 연출은 세션 완료 직후에 집중한다.
- 홈에서는 압박 없이 조용한 동기 부여만 제공한다.

피해야 할 것:
- streak를 과도하게 압박하는 카피
- CTA보다 큰 게임화 영역
- 대시보드처럼 많은 숫자를 나열하는 구성

### 5.3 저장 카드 복기

정책:
- v1 홈에서는 저장 카드 복기 모듈을 노출하지 않는다.
- 저장/복기는 `기록` 탭에서 처리한다.
- v1.1 복습 퀴즈 도입 시 홈 복기/퀴즈 유도 모듈을 재검토한다.

이유:
- v1 홈의 목적은 새 세션 시작이다.
- 저장 카드까지 홈에 넣으면 화면이 무거워진다.

### 5.4 빈 상태

정책:
- 홈에서는 `기록 없음`을 크게 강조하지 않는다.
- 메인 CTA가 빈 상태를 대체한다.
- 카피는 행동 초대형 해요체를 사용한다.

카피 예시:
- `오늘은 어떤 상황을 연습해볼까요?`
- `첫 대화를 끝내면 학습 기록이 쌓여요.`

기록/저장 카드의 빈 상태는 `기록` 탭에서 별도 처리한다.

## 6. 한도 UX

### 6.1 홈 노출 정책

정책:
- 남은 무료 세션 수를 홈에 상시 표시하지 않는다.
- 서버가 반환한 fresh `remaining` 값이 있을 때만 보조 정보로 표시한다.
- 남은 횟수가 1회 이하이거나 한도에 도달했을 때는 명확히 안내한다.

이유:
- 상시 노출하면 앱의 첫인상이 학습보다 제한 중심이 된다.
- v1은 수익화가 아니라 리텐션 검증 단계다.

### 6.2 한도 도달

문구 방향:
- `오늘 무료 학습을 다 했어요. 내일 또 만나요.` (정본 소유: [daily-limit-ux.md](daily-limit-ux.md) §3 — 본 문서는 참조)

정책:
- 중립 문구를 사용한다.
- streak 넛지는 가능하다.
- 업그레이드 CTA, 가격, 구독 유도는 노출하지 않는다.

### 6.3 한도 판정 시점

정책:
- 세션 생성 버튼 탭 직후 서버에서 판정한다.
- 클라이언트는 한도 카운트를 신뢰하지 않는다.

## 7. 생성 UX

### 7.1 생성 중

정책:
- 생성 단계 카피와 점진 로딩을 보여준다.
- 대기가 1초 이상이면 무채점 로딩 퀴즈 인터스티셜을 노출한다(정본: [loading-quiz-interstitial.md](loading-quiz-interstitial.md)).
- 준비 완료(첫 완성 상대역 턴 수신) 시 **강제 전환하지 않고** 하단 `대화 시작하기` 탭으로 넘어간다(첫 세션과 동일, 유저 탭 통일).
- 생성 중 취소는 v1에서 제공하지 않는다.

이유:
- 서버는 세션 시작 시점에 usage를 증가시킨다.
- 취소를 열면 취소/환불/슬롯 복구 UX가 필요해진다.
- v1에서는 이 복잡도를 열지 않는다.
- 준비 완료 시 자동전이는 인터랙션 도중 화면을 뺏어 이질적이므로, 두 표면(첫 세션·홈) 모두 유저 탭으로 통일한다.

### 7.2 생성 실패

정책:
- 같은 화면에서 비난 없는 에러와 재시도를 제공한다.
- 슬롯 환불 세부 정책은 UI에서 복잡하게 설명하지 않는다.
- 사용자가 다음 행동을 바로 알 수 있어야 한다.

카피 방향:
- `불러오지 못했어요. 다시 시도해볼까요?`

## 8. 오프라인 / 예외 상태

### 8.1 오프라인

정책:
- 기록/통계 열람은 가능하다.
- 새 학습 CTA는 비활성화하거나 온라인 필요 안내를 보여준다.
- 핵심 루프는 온라인 필수다.

카피 방향:
- `새 대화는 인터넷 연결이 필요해요.`

### 8.2 앱 백그라운드 / 회전

정책:
- 로컬 상태가 유지되는 경우 이어하기를 지원한다.
- 로컬 recoverable snapshot이 없으면 새로 시작한다.

---

## 9. UX 라이팅 원칙

원칙:
- 해요체
- 행동 초대형
- 비난 없는 에러
- 학습자 부담을 낮추는 표현
- 제한/한도는 정직하지만 과도하게 전면화하지 않음

선호:
- `오늘 5분 말하기`
- `오늘은 어떤 상황을 연습해볼까요?`
- `이어서 할 수 있는 대화가 있어요.`
- `불러오지 못했어요. 다시 시도해볼까요?`

회피:
- `대본 생성`
- `무료 횟수 소진`
- `실패했습니다`
- `제한 초과`
- 과금/업그레이드 암시 문구

## 10. 계측

PRD 필수 계측 개념:
- 세션 시작
- 세션 완주
- 턴 수
- 저장
- 한도 도달
- D1/D7 코호트

제안 이벤트명:
- `session_start`
- `session_complete`
- `turn_count`
- `saved_card_create`
- `limit_reached`

홈/학습 진입 보조 퍼널:
- 홈 노출
- 홈 CTA 탭
- 주제 선택
- 직접 입력 선택
- 세션 설정 변경
- 생성 시작
- 생성 성공
- 생성 실패
- 오프라인으로 새 학습 불가
- 미완 세션 이어하기 탭
- 미완 세션 새로 시작 탭

주의:
- 위 이벤트명은 제안명이다.
- 최종 event id는 Analytics 설계에서 확정한다.

## 11. 확정 결정 요약

| 항목 | 결정 |
|---|---|
| 첫 실행 | 홈 미노출, 게스트 시작 → 온보딩 2문항 → 첫 세션 |
| 첫 세션 | 쉬움, 5턴, beginnerFriendly 주제만 |
| 첫 완주 후 | 요약/성취/다음 유도/Google 저장 제안 우선 |
| 재방문 홈 CTA | `오늘 5분 말하기` |
| 재방문 진입 플로우 | 홈 CTA → 주제 선택 → 접힌 세션 설정 → 생성 |
| 세션 길이 | 재방문 기본 5턴, 10턴 옵션 |
| 레벨 | `profile.level` 기본, 접힌 설정에서 변경 |
| 직접 입력 | 재방문에서 보조 기능, 온보딩에서는 숨김 |
| 최근 주제 | core v1 제외 |
| 한도 노출 | 상시 표시 안 함, fresh value/한도 근접/도달 시 표시 |
| 생성 중 취소 | v1 미제공 |
| 홈 저장 카드 복기 | v1 미노출, 기록 탭에서 처리 |
| 홈 게임화 | 낮은 비중의 2~3개 상태 요약 |
| 미완 복귀 | 제목이 있고 미완이며 실제 말풍선이 1개 이상 렌더된 로컬 snapshot이면 이어하기, 없으면 새로 시작. 첫 상대방 발화만 표시된 상태도 이어하기 대상이고 진행 표시는 완료 학습자 턴 수(0 / 전체 턴)로 유지한다. 타이핑 스켈레톤만 보인 상태는 이어하기 후보가 아니다. 시간 만료 없음; 새 세션 시작 또는 대화 완료 시 폐기. |
