## 1. 목표

같은 의미의 카피가 화면마다 다른 톤·용어·표기로 보이는 것을 막는다. 라이팅 *규칙*을 한 곳에서 소유하고, 도메인 문서의 카피 *문자열*은 제자리에 두되 모두 이 표준에 conform + 링크한다.

핵심 원칙:
- 실패 원인을 사용자 탓으로 돌리지 않는다(해요체·비난 없는 에러).
- 격려가 1차, 정보(점수·한도·진척)는 보조 2차다.
- 점수/평가 압박을 카피에 섞지 않는다(정서적 안전, `dialogue-learning-flow.md` §12).
- 같은 문자열은 어느 화면에서든 한 곳이 소유한다(중복 해소 §7).

## 3. 톤 — 격려 우선 · 비난 없음

### 3.1 격려 우선 위계
- 축하/격려가 **1차**, 정보(한도·점수·진척)는 그 하단 **보조 인라인 1줄(2차)**. 정보가 격려를 시각적으로 압도하지 않는다.
- 근거: `daily-limit-ux.md:49`(서술문 — "축하가 1차, 한도 안내는 그 하단 보조 인라인 텍스트 1줄") + `gamification-emphasis.md` §4 서술. 표 행(`gamification-emphasis.md:35`)은 보조 근거.

### 3.2 비난 없는 에러 3원칙
1. 원인을 **사용자 탓으로 돌리지 않는다**(`exception-states.md:13`).
2. `실패/오류` 단정어를 쓰지 않는다.
3. 항상 **다음 행동 1개**를 제시한다(질문형 복구 CTA, §3.3).

근거: `exception-states.md:13`, `dialogue-learning-flow.md` §12, `saved-cards.md:48`.

### 3.3 복구·대체 프레이밍
- 재시도/복구는 **초대형 의문문**: `다시 해볼까요?` / `다시 시도해볼까요?` / `건너뛰고 다음으로 갈까요?`(`exception-states.md` §8, `turn-feedback-ia.md` §7).
- 대체 입력은 "실패 대체"가 아니라 **"선택 가능한 방식"**으로 표현: `마이크 없이도 채팅으로 말할 수 있어요`(`dialogue-learning-flow.md` §12, `exception-states.md:132`).

### 3.4 압박 vs 격려 경계
- **미래형 초대만 허용**(`내일 이어가면 N일째예요`). 손실형(`연속 기록 잃어요`)·카운트다운·타이머 금지.
- streak == 0이면 미래형 넛지를 붙이지 않는다.
- 근거: `gamification-emphasis.md:147`("압박/격려 구분 기준: 미래형 초대만 허용. 손실형·카운트다운 금지").

## 4. 한글화 기준

### 4.1 적용 경계 (신규 정책)
> 본 경계 규칙은 기존 결정의 통합이 아니라 **본 문서가 처음 도입**하는 신규 정책이다.

- 한글화 규칙은 **UI 크롬/시스템 카피에만** 적용한다.
- **학습 콘텐츠는 적용 제외**: 피드백 영어 예문, 문법 교정 세그먼트, 패러프레이즈 카드, 톤 슬라이더 문장은 의도된 **EN+KO 이중 노출**이다.
- 근거(콘텐츠가 본래 이중 언어임의 증거): `turn-feedback-ia.md` §3.2(문법 세그먼트 + 한국어 explanation), §4.2(톤 5단계 = 영어 문장 + 한국어 번역). *이 인용은 이중 언어 콘텐츠의 존재 증거일 뿐, 경계 규칙 자체의 선례는 아니다.*

### 4.2 영어 유지 vs 한글화 판정
| 케이스 | 처리 | 근거/이유 |
|---|---|---|
| `streak` | **한글화 → `연속` / `N일째`** | 불안 페르소나(A2~B1) 대상 영어 용어 노출은 진입장벽. 기존 `settings-data-account.md:111`·`gamification-emphasis.md:122-123`가 이미 "연속" 사용 |
| `XP` | **라틴 표기 유지(`+N XP`)** · 백스테이지 | 짧은 게임화 단위, 정착 한국어 등가어 없음. 노출은 완주 순간만(§5.3) |
| 제품 고유명(앱명 등) | 유지 | 고유명사 |
- 영어를 유지할 때는 **라틴 스크립트 그대로** 둔다. 음차(`엑스피`) 금지.

## 5. 표기 mechanics

### 5.1 구두점
- 평서문은 **마침표형 정본**: `내일 또 만나요.`(`daily-limit-ux.md:42`). 엠대시형(`— 내일 또 만나요`)은 PRD 표기 차이로 정본 아님.

### 5.2 느낌표
- `!`는 **모멘텀/축하 카피에만** 허용. 에러·차단·중립 안내엔 금지.
- "모멘텀" 정의 = **완주 / 연속(streak) 증가 / 복귀 환영**.
- 경계 사례 — 리셋 후 위로 카피(`gamification-emphasis.md:187` "다시 시작해요. 오늘이 1일째!"): 위로형은 `!` **1개까지** 허용하되 격앙된 표현 금지.

### 5.3 이모지
- v1 허용 팔레트 = **🔥(모멘텀/축하)만.** 에러·차단·중립 안내엔 이모지 금지.
- 확장은 본 표준 승인 전까지 미사용.

### 5.4 숫자/카운터
- 한국어 카운터: `N분` · `N일째` · `+N XP`(`gamification-emphasis.md:183-184`).
- 잔여 한도는 **비숫자 어포던스**(`오늘 한 번 더 할 수 있어요`). 잔여 수 노출 금지(`daily-limit-ux.md:38`).
- XP는 **백스테이지**: 완주 순간 `+N XP`만 노출, 그 외 화면 미노출(`gamification-emphasis.md` §9·§2).

## 6. 금지 목록 (2종 분리)

> 어휘 금지와 어포던스/기능 범위 제외는 **범주가 다르다.** 한 목록으로 섞지 않는다.

### 6.1 금지 어휘 (ux-writing 소유)
세 도메인의 `회피` 블록(`exception-states.md:139`, `daily-limit-ux.md:45`, `gamification-emphasis.md:191`)을 **union + 차이 보존 dedup**으로 통합한다(단순 concat 금지).

| 금지 어휘/표현 | 비고 | 출처 |
|---|---|---|
| `실패했습니다` / `오류` 단정 | 비난 없는 에러 위반 | exception-states |
| `제한 초과` | | exception-states |
| `무료 횟수 소진` | | daily-limit, gamification |
| 점수 비난(`점수가 낮아요` 등) | exception 블록에만 있던 항목 — 누락 금지 | exception-states |
| 손실형 표현(`연속 기록 잃어요` 등) | | daily-limit, gamification |
| 카운트다운/타이머 문구 | | daily-limit, gamification |
| 업그레이드/가격/과금 암시 | | 전 도메인 |

### 6.2 금지 어포던스/패턴 (도메인 소유, 교차 링크만)
- `잔여 숫자 배지`(상시 잔여 횟수 표시) 등은 **어휘가 아니라 기능 범위 제외**다. `daily-limit-ux.md` §12(v1 제외)가 소유한다. 본 문서는 교차 링크만 하고 어휘 목록에 흡수하지 않는다.

## 7. 소유 경계 & 중복 해소 우선순위

- **규칙**(보이스·톤·lexicon·localization·표기) → ux-writing.md 소유.
- **카피 문자열** → 도메인 카탈로그 소유.

### 7.1 중복 문자열 tiebreaker
한 문자열을 둘 이상이 주장할 때:
1. **가장 구체적인 도메인 카탈로그가 리터럴을 소유**한다.
2. 횡단 예외 카탈로그(`exception-states.md` §8)는 **도메인 홈이 있는 문자열을 *참조***한다. §8의 "단일 출처" 지위는 **도메인 홈이 없는 예외 카피 한정**으로 스코프한다.

### 7.2 알려진 중복 케이스 — 한도 도달 문자열
`오늘 무료 학습을 다 했어요. 내일 또 만나요.`
- **정본 소유 = `daily-limit-ux.md` §3**(이미 §11 결정 #4가 주장; copy-family로 streak 변형 `daily-limit-ux.md:40`과 함께 보존).
- 참조로 전환 대상: `exception-states.md:131`, `dialogue-learning-flow.md:53`, `home-learning-entry.md:267`.
